# HealthyLife Clinic – Appointment Scheduling System

Final Project for CIS 370: System Analysis and Design  
Buffalo State University – Spring 2025

## 🩺 Project Overview
A web-based appointment scheduling system for HealthyLife Clinic.  
It allows patients to:
- Book appointments online
- View doctor availability
- Receive confirmation/reminder alerts
